About the project

Making campus maintenance easier to report and follow.

This student group project is a frontend prototype for reporting and managing maintenance issues on campus.

Project scope

The prototype uses HTML, CSS and JavaScript. It stores demo account and request data in the browser's LocalStorage. It does not connect to a server or a shared database.
